# API Reference Specification

## C Systems Engine Command Line API
- `./shellforge_engine`: Launches interactive REPL shell.
- `./shellforge_engine -c "<command>"`: Executes command string and prints output.
- `./shellforge_engine --json -c "<command>"`: Executes command string and outputs structured JSON metadata.
- `./shellforge_engine --test`: Executes automated diagnostic test suite.
